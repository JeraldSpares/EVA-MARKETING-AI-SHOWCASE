# Enrollment Campaign Playbook
**Workflow:** Full Enrollment Season Campaign (October → March)
**Orchestrator:** Content Strategy Agent
**All Agents Involved:** Social Media, PR, Competitor Analysis, Drip Campaign, Designer, Data Analysis, SEO/Digital

---

## Overview

This playbook defines the coordinated multi-agent workflow for Enderun's annual enrollment campaign. Every agent has a defined role, timeline, and handoff point.

```
TRIGGER: October 1 (or as directed by Marketing Director)

Phase 1: SEED (Oct–Nov)
Phase 2: BUILD (Nov–Dec)  
Phase 3: PEAK (Jan–Mar)
Phase 4: CLOSE (Mar–Apr)
```

---

## Phase 1: SEED (October–November)

**Goal:** Generate awareness, collect early leads, warm up the audience.

### Week 1–2: Campaign Setup

**Content Strategy Agent:**
- [ ] Publish updated editorial calendar for enrollment season
- [ ] Brief all agents on this season's theme and messaging
- [ ] Confirm campaign name and codes with Marketing Director

**Competitor Analysis Agent:**
- [ ] Run competitor audit — what are schools promoting this season?
- [ ] Identify gaps Enderun can exploit
- [ ] Deliver "Competitive Landscape" report to all agents

**SEO/Digital Agent:**
- [ ] Activate Google Ads Brand Protection campaign
- [ ] Launch early-awareness Meta Ads (top of funnel)
- [ ] Update enrollment-related landing pages with current year info
- [ ] Confirm inquiry form is working and leads flow into CRM

**Drip Campaign Agent:**
- [ ] Audit all existing drip sequences — update dates and deadlines
- [ ] Confirm ActiveCampaign automations are active for new inquiries
- [ ] Set up "Early Bird" lead segment and sequence

**Designer Agent:**
- [ ] Produce campaign creative set: key visuals, color scheme, campaign logo
- [ ] Deliver social media template set to Social Media Agent
- [ ] Produce ad creatives for Digital Agent (3 variants each: awareness, consideration, conversion)

**Social Media Agent:**
- [ ] Begin early-awareness content (program spotlights, campus life)
- [ ] Post "Applications are now open" announcement
- [ ] Begin weekly scholarship teasers

**PR Agent:**
- [ ] Draft press release: "Enderun Opens Applications for SY [Year]"
- [ ] Send to education desks of major publications
- [ ] Pitch "best hospitality school" story angle to lifestyle editors

---

## Phase 2: BUILD (November–December)

**Goal:** Nurture leads, build desire, prepare for January peak.

**Content Strategy Agent:**
- [ ] Shift content ratio to +20% enrollment-focused
- [ ] Assign alumni feature series to Social Media Agent
- [ ] Schedule holiday content (non-enrollment) to maintain warmth

**Drip Campaign Agent:**
- [ ] Monitor open rates — adjust subject lines if below 30%
- [ ] Activate "Parent Nurture" sequence for parent-tagged leads
- [ ] Segment and tag leads by program interest for targeted follow-up

**Data Analysis Agent:**
- [ ] Deliver mid-phase report: inquiries vs. same period last year
- [ ] Flag which channels are generating the most leads
- [ ] Recommend budget reallocation if any channel underperforms

**SEO/Digital Agent:**
- [ ] Increase Meta Ads budget to middle-funnel (consideration) campaigns
- [ ] Launch remarketing to all website visitors and social engagers
- [ ] Publish 2 SEO blog posts (long-form, high-intent keywords)

**Social Media Agent:**
- [ ] Run "Meet Our Faculty" series (credibility building)
- [ ] Post "Why Enderun" student testimonial videos
- [ ] Begin Open House teaser content

---

## Phase 3: PEAK (January–March) ⚡

**Goal:** Maximum lead generation and conversion to applications.

### January: Launch Blitz

**ALL AGENTS — January 2:**
- Full campaign goes live simultaneously across all channels
- No gaps — every channel active on Day 1

**Social Media Agent (Daily in January):**
- [ ] Daily posts across all platforms
- [ ] Application deadline countdown content
- [ ] Daily IG Stories engagement: polls, Q&A, countdowns
- [ ] 3x/week TikTok: campus tours, student day-in-life, Les Roches content

**SEO/Digital Agent:**
- [ ] Maximum Meta Ads budget — conversion campaigns live
- [ ] Google Ads enrollment keywords at peak bidding
- [ ] Launch Lead Ad forms on Facebook and Instagram
- [ ] A/B test 2 ad creatives — report winner to Data Analysis Agent weekly

**Drip Campaign Agent:**
- [ ] All sequences must be running and confirmed
- [ ] Add "Open House Invite" touchpoint to all active sequences
- [ ] Monitor and accelerate abandoned application sequence

**PR Agent:**
- [ ] Open House press coverage — invite 5 media outlets
- [ ] Issue press release 2 weeks before Open House
- [ ] Arrange student and faculty spokesperson interviews

**Data Analysis Agent:**
- [ ] Weekly pulse reports every Monday
- [ ] Funnel conversion analysis every 2 weeks
- [ ] Real-time alert system: if leads drop >20% vs. target, flag immediately

### February: Open House Month

**PR Agent + Social Media Agent + Designer Agent:**
- [ ] Joint effort: Open House campaign is the centerpiece of February
- [ ] Live event coverage on all platforms
- [ ] Post-event recap press release within 24 hours
- [ ] Testimonial content from Open House attendees

**Drip Campaign Agent:**
- [ ] Segment: Open House attendees → activate post-visit sequence
- [ ] Segment: Open House registrants who didn't show → activate re-engagement sequence

### March: Final Push

**Social Media Agent:**
- [ ] Hard deadline countdown (7 days, 3 days, 1 day)
- [ ] "Last chance" urgency content — not fear, but genuine encouragement
- [ ] Student acceptance celebration prep content ready

**SEO/Digital Agent:**
- [ ] Surge remarketing budget — catch everyone who visited and hasn't applied
- [ ] Update ad copy to include specific deadline date

**Drip Campaign Agent:**
- [ ] Final "application closing" email to all warm leads who haven't applied
- [ ] Urgent 3-email mini-sequence for abandoned applications

- [ ] ROI by channel and campaign

**Content Strategy Agent:**
- [ ] Archive this season's campaign assets and learnings

- [ ] Debrief all agents with performance summary

## Handoff Protocol Between Agents

When one agent produces output that another needs:

1. Save file to `/output/[category]/` with naming convention: `YYYY-MM-DD_[agent]_[description].md`
2. Reference the file in the next agent's task
3. Flag as `[READY FOR HANDOFF]` in the document header

**Example:**
- Designer Agent produces ad creatives → saves to `/output/campaigns/2026-01-15_designer_jan-enrollment-ads.md`
- Digital Agent picks up creatives from that file for Meta Ads upload
- Data Analysis Agent reviews ad performance and reports to Social Media and Digital agents

---

## Emergency Escalation Protocol

**If lead volume is >30% below target:**
1. Data Analysis Agent flags immediately
2. Marketing Director convened within 24 hours
3. Digital Agent proposes budget surge options
4. Competitor Analysis Agent checks if a competitor launched a disruptive campaign
5. Content Strategy Agent adjusts messaging if needed

**If a competitor launches a major campaign:**
1. Competitor Analysis Agent issues an alert within 24 hours
2. All agents receive competitive brief
3. Counter-messaging deployed within 48 hours across: social, ads, email
